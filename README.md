# 오수펫 추모공원 · 2D 이미지

같은 반려동물의 사진 1~6장을 올리면 완성된 전신 실사 이미지 한 장을 미리 보고 PNG로 저장할 수 있습니다. 생성에는 OpenAI API 키 하나가 필요합니다.

출력은 가로 4:3(2304×1728)의 불투명 PNG입니다. 약 20° 앞 사선의 와이드숏으로 생성한 뒤, 투명 배경에서 동물의 가장 높은 귀나 꼬리 끝부터 가장 낮은 발끝까지의 높이를 잽니다. 전신이 화면 높이의 60%를 넘으면 종횡비를 유지해 높이 1,036px로 줄이고 중앙에 배치합니다. 그 이하이면 원래 크기와 위치를 유지합니다. 서버는 털 가장자리의 투명도를 반영해 녹색(#00B140) 배경과 합성하며, 미리보기와 다운로드는 같은 PNG를 사용합니다.

## 로컬 실행

1. Node.js 20 이상을 설치합니다.
2. 프로젝트 폴더에서 `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`에 자신의 키를 입력합니다.
3. `npm ci`로 PNG 처리 라이브러리를 설치한 뒤 `npm start`를 실행하고 [로컬 사이트](http://localhost:3000)를 엽니다. 다른 포트를 쓰려면 `.env`의 `PORT`를 변경하세요.

사진을 선택하고 생성 버튼을 누른 뒤 결과를 PNG로 저장합니다. 다시 생성하면 OpenAI 이미지 편집 API가 한 번 더 호출됩니다. 원본 사진과 결과 이미지는 서버 디스크에 저장하지 않습니다.

## 검증 및 배포

`npm test`는 외부 이미지 생성 호출을 모의 응답으로 대체해 검증합니다. Render에 별도 서비스로 배포할 때는 이 프로젝트를 서비스 루트로 지정하고 빌드 명령을 `npm ci`, 시작 명령을 `npm start`로 설정하세요. 서비스 환경 변수에 `OPENAI_API_KEY`를 등록합니다.
